# QB转TR转移做种

把多个 qBittorrent 已完成的种子迁移到 Transmission 继续做种。

## 功能

- 扫描多个 qBittorrent 实例里**已完成（进度 100%）**的种子
- 导出种子（自带 tracker / passkey）加入 Transmission，并按标签标记
- 加入后立即触发校验，校验一完成就自动开始做种
- 可选：加入 TR 后从 qB 移除任务（**只删任务，不删数据文件**）
- 定时自动转移 + 自动做种，完成后 Telegram 通知

## 安装

1. 在 DIAN115 中安装本插件（`.dian115p` 包）
2. 在插件设置里填写 qBittorrent 实例与 Transmission 地址
3. 手动运行「转移到 Transmission」任务，或开启定时自动转移

## 设置说明

| 设置 | 说明 |
| --- | --- |
| qBittorrent 实例 | 一行一个：`名称\|地址\|用户名\|密码\|路径前缀\|APIKey\|分类`。密码认证填用户名+密码；API Key 认证只填第 6 段 |
| Transmission 地址 | RPC 地址，通常为 `http://IP:9091` |
| TR 用户名 / 密码 | TR 开启 RPC 认证时填写 |
| 路径映射规则 | qB 与 TR 挂载路径不一致时填写（一致则留空） |
| 单轮最多转移 | 默认 20，防止一次打满两端 |
| 定时自动转移 + 开始做种 | 默认开启，每 5 分钟执行 |
| 加入 TR 后从 qB 移除任务 | 默认开启，只删任务不删数据 |
| 试运行 | 开启后只列出计划，不实际转移 |

## 工作流程

```
qB 已完成种子
   → 导出（含 tracker）加入 TR（暂停 + 打标签）
   → 立即校验
   → 校验完成自动开始做种
   → （可选）从 qB 移除任务，数据保留
```

## 说明

- 校验由 Transmission 完成；小种子几秒、大种子按磁盘大小而定，校验完即做种
- 路径两边一致时无需任何映射配置
- 种子文件备份默认开启，TR 丢失时可凭 hash 重新加入
